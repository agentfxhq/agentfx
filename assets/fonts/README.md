# Bundled fonts

Every font in this directory is licensed under the SIL Open Font License, Version 1.1.
The licence text and all copyright notices are in [`OFL.txt`](OFL.txt). The fonts are
unmodified copies; `fonts.json` lists the families Reel Script registers.

Versions, copyright holders and licence strings were read from each file's `name` table
(IDs 0, 5, 13).

and copyright notices go with them and the fonts are not sold on their own. Modified
versions must not use a Reserved Font Name (here: "Source").
