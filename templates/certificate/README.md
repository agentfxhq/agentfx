# Certificate

Certificate of completion or achievement: double frame, title, recipient, what it is for, date,
signature line with role, issuer logo and a seal. Batch-friendly: give a `recipients` table and
render one still per row (`index` = row; `batch_params()` in `render_template.py` lists the param
sets). Serves "certificate generator", "zertifikat erstellen", "urkunde erstellen".
