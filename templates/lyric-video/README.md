# Lyric video

Lyric video maker: paste lyrics (one line per row), upload the song and set its tempo; each line lands on the beat grid (`bpm`, `offset` = first line in seconds, `beats_per_line`) with a karaoke colour sweep or a word-by-word rise, over colour light that breathes with the track. Per-line times (`times`, e.g. from forced alignment) override the grid line by line. Serves "lyric video maker" (1.1k/month). Default track: `night-drive.mp3` (see `../LICENSE-audio.md`); the default lyrics are written for it.
